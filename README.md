Weather Diary — дневник погоды
Автор: Ибрагимов Исхак Шамилевич
Дата: 01.05.2026

Описание проекта
Weather Diary — это графическое приложение на Python для ведения дневника погоды. Позволяет добавлять записи о погоде с проверкой данных (дата и температура), просматривать их в таблице и фильтровать по дате или температуре. Все данные сохраняются в файл weather_data.json, что позволяет не терять записи после закрытия программы.

Возможности
Добавление записей: дата (ГГГГ-ММ-ДД), температура (число), описание (не пустое), осадки (да/нет).
Валидация ввода: дата — только в правильном формате; температура — только число; описание не пустое.
Фильтрация по дате и температуре.
Сохранение и загрузка данных из weather_data.json.
Интуитивно понятный интерфейс на Tkinter.

Требования
Python 3.7+
Библиотека Tkinder (входит в стандартную поставку Python).

Инструкция по запуску
1. Убедись, что установлен Python 3.7 или новее.
2. Склонируй репозиторий:
git clone https://github.com/[твой_логин]/weather-diary.git
cd weather-diary
3. Запусти приложение:
python main.py
4. Для работы с Git используй стандартные команды (git add ., git commit -m "...", git push).

Примеры использования
Добавить запись: заполни все поля и нажми «Добавить запись».
Фильтровать по дате: введи дату и нажми «Фильтровать».
Фильтровать по температуре: введи температуру и нажми «Фильтровать».
Данные сохраняются автоматически при добавлении записи.
